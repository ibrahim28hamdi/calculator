# Python Calculator

A calculator web app built using Python and Streamlit.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percent
- Parentheses
- Decimal numbers
- Delete button
- Clear button
- Scientific functions:
  - Square root
  - sin
  - cos
  - tan
  - log
  - ln
  - pi
  - square

## How to run

1. Install Python.
2. Open Terminal / CMD in this folder.
3. Install requirements:

```bash
pip install -r requirements.txt
```

4. Run the app:

```bash
streamlit run app.py
```

The calculator will open in your browser.
